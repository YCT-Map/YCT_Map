# Roadmap — YCT Map

This document records the approved product roadmap.

Only clearly known or approved work appears here. Speculative ideas belong in `BACKLOG.md`.

---

## V1 — Core Campus Navigation

**Status:** IN PLANNING / PRE-BUILD

**Goal:** A genuinely usable product that students, staff and visitors can use to navigate YabaTech.

### Included in V1

- Map-first interface (mobile-first, desktop-compatible)
- Campus location search
- Browse by category
- Route visualization with distance and estimated walking time
- Basic written step-by-step guidance
- GPS-based live navigation with rerouting
- Manual starting point selection when GPS is unavailable
- Public contributions (without an account)
- Contribution moderation queue
- Editor / administrator authenticated interface
- Location management (add, edit, verify)
- Internal location support (departments, offices, rooms)
- Demonstration dataset for development and testing
- Field verification workflow

### Exit Criteria for V1

- A student can search, navigate and contribute without an account.
- An editor can log in and manage campus data.
- The application is deployed and accessible on real devices.
- At least a representative set of real YabaTech locations are FIELD VERIFIED.
