# Project Resume Prompt

Read these documents in order:

1. `docs/project/operations/CURRENT_STATE.md`
2. `docs/project/product/PROJECT_BRIEF.md`
3. `docs/project/product/V1_SCOPE.md`
4. `docs/project/technical/ARCHITECTURE.md`
5. `docs/project/operations/DECISIONS.md`
6. `docs/project/governance/ENGINEERING_RULES.md`
7. `docs/project/governance/SPRINT_PROTOCOL.md`
8. Latest entry in `docs/project/operations/SPRINT_LOG.md`

Then inspect the actual repository.

Do not implement anything yet.

Report:

- what the product is;
- current architecture;
- current build phase;
- completed work;
- current branch/state;
- known blockers;
- next planned sprint;
- any mismatch between documentation and repository reality.

Repository reality wins over stale documentation, but do not silently rewrite documentation.

Stop after the report.
